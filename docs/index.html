OFAC Sanctions Screening

Live — OFAC · UN · EU

Every Stellar wallet score includes real-time sanctions screening against OFAC SDN, UN Security Council, and EU Financial Sanctions lists. A sanctioned wallet automatically returns score 0 and status BLACKLISTED.
